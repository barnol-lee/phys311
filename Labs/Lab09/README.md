For this lab, there are render and engine subfolders that contain all the relevant needs for a physics engine and the corresponding animation. Additionally, there are four files of interest: main.js, scene1.js, scene2.js, and scene3.js. Really, main.js does not really have anything useful to speak of; this is because it was a sort of sandbox for making the scene folders. All of the interestingly crafted physics scenes are, therefore, in the scene folders. To change scenes requires unfortunately that you go into the index.html file and find the line that has src="scene1" written near the end, and then you simply put in the quotations the file you wish to be used. I will now explain what each scene is:
1. Scene 1: A lot of balls trapped in a box. The restitution can be easily modified in the World instantiation in the scene1.js file. This one was essential for benchmark purposes, and hence it also has grid implementation to show speed up.
2. Scene 2: A couple of balls under Newtonian gravity, while in a box as well for viewing convenience. The special thing here is energy-boundedness.
3. Scene 3: A lot of balls connected in series by springs, the first and last of which are static, while in a box. This one is fun to watch, and was what I spent the most time on trying to work out the kinks for momentum conservation. As a reesult, the best thing here is that.
