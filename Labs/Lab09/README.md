For this lab, there are render and engine subfolders that contain all the relevant needs for a physics engine and the corresponding animation. Additionally, there are four files of interest: main.js, scene1.js, scene2.js, and scene3.js. Really, main.js does not really have anything useful to speak of; this is because it was a sort of sandbox for making the scene folders. All of the interestingly crafted physics scenes are, therefore, in the scene folders. To change scenes requires unfortunately that you go into the index.html file and find the line that has src="scene1" written near the end, and then you simply put in the quotations the file you wish to be used.
